# Streamlit 컴포넌트 쇼케이스

입력 위젯, 차트, 레이아웃, 상태 메시지, 폼, 데이터 표 등 Streamlit 웹 앱에서 활용할 수 있는 요소를 둘러보는 예제입니다. 화면의 샘플 데이터는 앱 안에서 생성되므로 별도의 데이터 파일 없이 실행할 수 있습니다.

## 실행 방법

1. 필요한 패키지를 설치합니다.

   ```bash
   pip install -r requirements.txt
   ```

2. 앱을 실행합니다.

   ```bash
   streamlit run streamlit_app.py
   ```
